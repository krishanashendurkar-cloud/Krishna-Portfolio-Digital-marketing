KRISHNA SHENDURKAR — PORTFOLIO WEBSITE
=====================================

HOW TO PREVIEW
1. Extract this ZIP.
2. Keep index.html, style.css, script.js, the assets folder, and the PDF in the same main folder.
3. Double-click index.html to preview in your browser.

HOW TO PUBLISH WITH GITHUB PAGES
1. Create a GitHub repository (for example: krishna-portfolio).
2. Upload the CONTENTS of this extracted folder to the repository root.
   IMPORTANT: index.html must be at the repository root, not inside another nested folder.
3. In GitHub, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. Wait for GitHub Pages to publish the site.

ASSET PATHS
All image references use relative paths such as assets/kds-digital-logo.jpeg.
Do not rename the assets folder or the files inside it unless you also update index.html.
